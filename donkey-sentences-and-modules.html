Donkey Sentences and ML Modules

Date: 2026-11-04 (unpublished)

In the field of formal semantics for natural languages, there is a problem of so-called “donkey sentences”. Consider how you might translate this sentence into formal logic:

 If a farmer owns a donkey, she is rich.  \text{ If a farmer owns a donkey, she is rich. }  If a farmer owns a donkey, she is rich. 

Intuitively, I would reach for something like:

∀f∈Farmer. (∃d∈Donkey. OWNS(f,d))→RICH(f) ∀ f ∈ \mathbf{Farmer}. \space (∃ d ∈ \mathbf{Donkey}. \space \text{OWNS}(f, d)) → \text{RICH}(f) ∀f∈Farmer. (∃d∈Donkey. OWNS(f,d))→RICH(f)

We assume we have some sets Farmer,Donkey\mathbf{Farmer}, \mathbf{Donkey}Farmer,Donkey and predicates OWNS,TALL\text{OWNS}, \text{TALL}OWNS,TALL. But what about this sentence?

 If a farmer owns a donkey, she rides it.  \text{ If a farmer owns a donkey, she rides it. }  If a farmer owns a donkey, she rides it. 

It is tempting to write

∀f∈Farmer. (∃d∈Donkey. OWNS(f,d))→RIDES(f,d) ∀ f ∈ \mathbf{Farmer}. \space (∃ d ∈ \mathbf{Donkey}. \space \text{OWNS}(f, d)) → \text{RIDES}(f, d) ∀f∈Farmer. (∃d∈Donkey. OWNS(f,d))→RIDES(f,d)

but this is meaningless formally, because the variable ddd is not in scope in RIDES(f,d)\text{RIDES}(f, d)RIDES(f,d). We need to pull the quantifier out so it scopes over the whole implication. Knowing that →→→ is contravariant in its left argument, we might also intuit that the quantifier must be changed from existential to universal:

∀f∈Farmer. ∀d∈Donkey. OWNS(f,d)→RIDES(f,d) ∀ f ∈ \mathbf{Farmer}. \space ∀ d ∈ \mathbf{Donkey}. \space \text{OWNS}(f, d) → \text{RIDES}(f, d) ∀f∈Farmer. ∀d∈Donkey. OWNS(f,d)→RIDES(f,d)

So the problem, in short, is: how do we assign meaning to the noun phrase “a donkey” in isolation, if it needs to introduce a quantifier whose scope isn’t semantically limited to the noun phrase itself?

With the disclaimer I don’t have formal training in linguistics, and this might not be a new idea, some of the existing approaches to this problem bear striking resemblance to how Rossberg, Russo, and Dreyer (2010) describe the “F-ing” semantics of ML modules.

In the linguistics world, we have discourse representation theory. Emphasis mine:

A discourse representation structure (DRS) is a mental representation built up by the hearer as the discourse unfolds. A DRS consists of two parts: a universe of so-called “discourse referents”, which represent the objects under discussion, and a set of DRS-conditions which encode the information that has accumulated on these discourse referents.

An indefinite like “a donkey” is treated not as a quantifier but simply as device for introducing a discourse referent and one or more conditions; on the DRT account, indefinites have no quantifying force of their own. What quantifying force they seem to have is not theirs, but derives from the environment in which they occur.

If we replace discourse referents ↦ declared type variables and conditions ↦ declared bindings (propositions are types!), this is identical to the notion of a translucent abstract type in the ML modules world. To quote my previous post on 1ML:

A better mental model of an abstracted type is something like (α:κ‾.Σ)(\overline{α : κ}. Σ)(α:κ.Σ) — a large type expression that has a number of free variables, and is equipped with a description of those variables… but does not prescribe an interpretation for the variables, allowing them to later become existentially quantified, universally quantified, or substituted with concrete types.

Okay, this is glossing over a lot of detail here, and I probably have linguists in my audience mad at me. Natural languages are a lot more complicated than programming languages. For example, you need machinery for keeping track of how pronouns are bound to existing discourse referents.

Nevertheless, at some level, it’s exactly the same logical transformation being made! The premise contains what looks like an existential quantifier ∃α‾∃ \overline{α}∃α, but it gets pulled out and turned into a universal quantifier ∀a‾∀ \overline{a}∀a in the conclusion.

What to make of this correspondence?

There is lots of room for cross-pollination between linguistics and PL, and it would be cool for someone with more background in linguistics than me to explore it. For example, the SEP article on discourse representation theory I quoted from above also brings up model theory as a way of understanding the semantics of discourse. I’ve never seen this discussed in the ML modules literature, and I would love to see how it transfers.

The linguistics and PL perspectives are both valuable we think about mathematical natural language. You can’t write about module systems without bringing up an abstract algebra example, so consider this sentence:

If xxx is an element of a finite group, then xxx has finite order.

Although “order” is not a pronoun, there is still something referential or anaphoric about it—it is only defined with respect to the specific group structure mentioned. In most systems of mathematical foundations, including ZFC and type theory (as it is typically done), the existence of this group structure is be a hypothesis, not an inherent part of the type of xxx. Nonetheless, “the order of xxx” is perfectly unambiguous concept. We can explain this by positing that the noun phrase “a finite group” introduces the group as a discourse referent which remains in scope for the consequent part of the sentence.
